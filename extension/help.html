↓Video Tools

Install once. Save from the toolbar.

  1. Run Setup.cmd in the project folder. This installs an isolated Python runtime and registers the local helper for your user account.
  2. Open brave://extensions, chrome://extensions or edge://extensions. Turn on Developer mode.
  3. Choose Load unpacked and select the project’s extension folder.
  4. Pin Video Tools from the browser’s extensions menu.

Open a video and click Video Tools. For a timeline with several videos, select the desired item. You can also paste a link or right-click a video/link and choose Download with Video Tools.

Choose your part

Drag the two handles, type exact timestamps, or use the ± buttons. Alt changes the step to 0.1 seconds; Shift changes it to 10 seconds. Zoom the timeline for finer dragging. Use player time copies the current position. Preview seeks and plays the page’s video from the selected start; it does not stop automatically at your end.

Use the arrow beside Download to choose video, audio or transcript. That choice stays saved. Clip boundaries are stored separately for each video for this browser session.

Local files and privacy

The helper runs when the extension needs it. Jobs continue when the popup closes. Downloads go to your Videos/Video Tools folder until you choose another destination in Settings. Existing files are preserved; incomplete work stays in .video-tools-work within the destination.

No analytics, cloud processing, automatic browsing history collection or automatic browser-cookie reading. Requests go to the video provider. If you choose a cookies file in Settings, yt-dlp can use and refresh that file. Disconnect it when finished; do not put it in Git.

What works

YouTube uses the existing YouTube Tools project. Other sites use yt-dlp and detected media URLs. X and Facebook support depends on the specific video, visibility, login requirements and current site behavior. Protected DRM media, live broadcasts, browser-only blob streams and some private videos cannot be downloaded. Not every page has a duration before it is analyzed.

Transcripts use available captions. No captions means no transcript; speech-to-text is not included. Selected transcripts contain whole overlapping cues. Precise video cuts re-encode; turning that setting off uses faster cuts that can land near keyframes.

Troubleshooting

If the helper is missing, rerun Setup.cmd and use Reconnect. If the project was moved, rerun setup. FFmpeg and FFprobe must be on PATH; restart the browser after installing them. A direct video link is often more reliable than a feed URL. Keep yt-dlp current using Update Tools.cmd; this only changes this extension’s isolated environment.
